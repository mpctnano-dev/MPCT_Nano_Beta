Parking

Where to Park

Use ParkMobile pay-by-phone options in Lot P64 (2551 Pine Knoll Drive) for $5/hour.
  1. Download the ParkMobile app, register online.
  2. Or call 877-727-5950 to set up an account before using this option.

Each lot has its own ParkMobile code — Lot P64 is: Zone 4691

NAU Parking Services

Accessible Parking

ADA stalls available in Lot P64 with a valid permit plus state placard or plate.

EV Charging

Nearest station is at Lot P16A — confirm availability before you arrive.

Bus / Shuttle

The weekday shuttle stops at Skydome, a 5-minute walk from the lab.

Bicycle Parking

Racks are available at the Building 98E entrance.
